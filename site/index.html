01 — 功能

为长时间阅读而做的取舍

不做批注云同步、不做书城、不做社交。所有设计都朝向同一件事：让你在文档里待得更久一点。

PDF 连续滚动

pdf.js 渲染到画布，叠加透明文本层，长文档按视口懒加载页面。滚动像翻一本装订好的册子，而不是一页页点击翻页。

目录 · 缩略图 · 全文搜索

同一个侧栏分三格：按章节大纲跳转、按缩略图定位、按关键词在全文中匹配并高亮命中处。

Markdown 活排版

渲染在 Rust 端完成，支持表格、任务列表、脚注、删除线与自动链接，代码块带语法高亮；标题层级自动生成目录锚点。

纸白 · 夜读 · 护眼

三套主题不只换底色：纸张纹理、文字对比度、分隔线与代码配色一起变，夜里读长文不再刺眼。

可调的排版

正文字号 15–21px、行高三档、版心 620–820px，另有专注模式收起一切非正文元素。

本地优先

无账号、无云同步、无遥测。文档与阅读记录只存在本机目录，断网时功能一个不少。

  • 进度记忆页码、缩放与滚动偏移自动保存，下次打开回到原处
  • 命令面板Ctrl / Cmd + K 搜书、跳章节、切主题、开设置
  • 拖拽导入把文件拖进窗口即入书架，原文件留在原处
  • 跨平台同一份代码构建 Windows、macOS 与 Linux 安装包

02 — 界面

一套排版语言，两种文档

标题用楷体，正文用宋体，朱砂色只用来标记"你正在这里"。

书架不是文件列表

封面按纸色分组，进度条压在书脊下沿；最近读的那本永远在最上面，收藏的会被钉住。

正文区只有正文

页眉、页码、工具栏都在边缘待命，专注模式下连侧栏一起收起，版心宽度随窗口自适应。

设置即所见

主题、字号、行高与版心改动立即生效，不需要确认，也不需要重启应用。

数据只放在程序目录

配置、书架与阅读进度写入安装目录下的 data/（state.json 与 WebView 缓存）， AppImage 则写在其同级目录。不向系统其他位置散落文件；把整个目录复制走，阅读记录跟着走。

首次打开提示

macOS 安装包未做公证，若提示"无法验证开发者"，请右键点击应用选择「打开」。Linux 的 AppImage 需要先 chmod +x 再运行。所有历史版本与校验信息见 GitHub Releases。

04 — 技术

小体积，少依赖，无网络

界面是原生 HTML / CSS / ES Module，没有打包器；外壳由 Rust 与 Tauri 2 提供，直接复用系统 WebView， 因此安装包只有几 MB，冷启动通常在 2 秒内。Markdown 解析放在 Rust 侧，PDF 交给 pdf.js， 两者都不需要联网下载任何资源。

项目使用 MIT 协议开源，构建脚本会把所有下载的依赖收在工作区内，安装包由 GitHub Actions 在三个平台上分别产出。

npm install
npm run dev

# 构建当前平台安装包
npm run bundle

05 — 问答

常见问题

阅笺是免费的吗？

是。阅笺以 MIT 协议完全开源，桌面端全部功能免费，没有会员、订阅或内购。

我的文档会被上传到服务器吗？

不会。阅笺没有账号体系、没有云同步、没有遥测。PDF 与 Markdown 文件始终留在本机，断网也能读完。

支持哪些文档格式？

PDF 与 Markdown（.md / .markdown）。Markdown 按 GitHub 风格渲染，包含表格、任务列表、引用、脚注与删除线，代码块带语法高亮。

支持 Windows、macOS 和 Linux 吗？

三端都有安装包。Windows 提供 NSIS 安装程序，macOS 提供 Intel 与 Apple Silicon 通用的 dmg，Linux 提供 deb 与 AppImage。系统要求：Windows 10 1803+、macOS 10.15+、带 WebKitGTK 4.1 的现代发行版。

macOS 提示"无法验证开发者"怎么办？

安装包尚未做 Apple 公证。在访达中右键点击应用并选择「打开」，或执行 xattr -dr com.apple.quarantine "/Applications/YueJian Reader.app" 后再启动。

配置和阅读进度保存在哪里？

保存在程序安装目录下的 data/ 文件夹（state.json 与 WebView 缓存），不写入系统其他位置。复制整个程序目录即可迁移全部阅读记录。

可以参与开发吗？

可以。源码、构建脚本与设计文档都在 GitHub 仓库，欢迎提交 Issue 与 Pull Request。
