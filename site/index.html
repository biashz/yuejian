01 — 功能

为长时间阅读而做的取舍

不做批注云同步、不做书城、不做社交。所有设计都朝向同一件事：让你在文档里待得更久一点。

PDF 连续滚动

pdf.js 渲染到画布，叠加透明文本层，长文档按视口懒加载页面。滚动像翻一本装订好的册子，而不是一页页点击翻页。

电子书：分页与滚动

EPUB、FB2、MOBI、AZW3、CBZ 直接打开，分页与连续滚动随时切换；单页 / 双页、书签、全书搜索与进度刻度一并到位，位置按 CFI 记住，换字号、改窗口都不丢。

朗读与自动滚动

用系统本地嗓音逐句朗读，当前句带淡色高亮、自动翻页；自动滚动按档匀速推进。两者共用一条贴底辅助条，翻页或滚轮即停，不抢方向盘。

划线 · 笔记 · 摘录

选中文字即可取五色划线，画在正文之上、不改书的排版；500 字以内的笔记挂在划线上，侧栏可回看编辑；一键导出 Markdown 摘录，带出处、颜色与笔记。

Markdown 活排版

渲染在 Rust 端完成，支持表格、任务列表、脚注、删除线与自动链接，代码块带语法高亮；标题层级自动生成目录锚点。

目录 · 缩略图 · 全文搜索

同一个侧栏分三格：按章节大纲跳转、按缩略图定位、按关键词在全文中匹配并高亮命中处。书架搜索框还能跨书搜正文，命中直接落到那一行、那一页。

纸白 · 夜读 · 护眼

三套主题不只换底色：纸张纹理、文字对比度、分隔线与代码配色一起变，夜里读长文不再刺眼。

可调的排版与字体

正文字号、行高与版心随调随生效；电子书另有版式面板，系统宋体 / 黑体 / 楷体外，可选 5 款 OFL 开源字体按需下载——安装包不带字体，用过一次即离线可用。

本地优先

无账号、无云同步、无遥测。文档、划线与阅读记录只存在本机目录；除可选字体下载与更新检查外，运行时不需要网络。

  • 进度记忆页码、缩放与滚动偏移自动保存，下次打开回到原处
  • 命令面板Ctrl / Cmd + K 搜书、跳章节、切主题、开设置
  • 分类 · 状态 · 排序自建分类，在读 / 未读 / 读完自动分组，四轴排序会记住
  • 跨书检索书架搜索框连正文一起搜，命中直接落到行、页或章
  • 打印与导出文本类可打印或导出独立 HTML，PDF 与电子书另存原文件
  • 拖拽导入把文件拖进窗口即入书架，原文件留在原处

02 — 界面

一套排版语言，四种文档

标题用楷体，正文用宋体，朱砂色只用来标记「你正在这里」；电子书另有一条贴底生长的「书口」带。

书架不是文件列表

封面按纸色分组，进度条压在书脊下沿；按最近打开、书名或进度排序，在读 / 未读 / 读完自动分组，移除后的六秒里还能撤销。

正文区只有正文

页眉、页码与工具带都在边缘待命；电子书的章节名与进度轨道贴底生长，专注模式下连侧栏一起收起。

设置即所见

主题、字号、行距与版心立即生效；电子书可另开版式面板，切分页 / 滚动、下载开源字体，不需要确认，也不需要重启。

数据只放在程序目录

配置、书架、划线与阅读进度写入安装目录下的 data/（state.json）， 跨书检索索引与按需下载的字体也落在同目录的 search/、fonts/，AppImage 则写在其同级目录。 不向系统其他位置散落文件；把整个目录复制走，阅读记录跟着走。

首次打开提示

macOS 安装包未做公证，若提示"无法验证开发者"，请右键点击应用选择「打开」。Linux 的 AppImage 需要先 chmod +x 再运行。所有历史版本与校验信息见 GitHub Releases。

装一次，之后自动更新

Windows 版启动几秒后会静默检查 GitHub Releases，发现新版本就在后台下载；设置 → 更新里可手动检查、 查看下载进度，点「立即重启安装」即可完成升级。升级会先卸载旧版本，data/ 默认保留。 这是应用仅有的两个联网动作之一，另一个是按需下载的开源字体，两者都不影响离线阅读。

04 — 技术

小体积，少依赖，默认不联网

界面是原生 HTML / CSS / ES Module，没有打包器；外壳由 Rust 与 Tauri 2 提供，直接复用系统 WebView， 因此安装包只有几 MB，冷启动通常在 2 秒内。Markdown 解析与文本解码放在 Rust 侧，PDF 交给 pdf.js， 电子书由 foliate-js 排版；除可选的字体下载与更新检查外，运行时不请求网络。

项目使用 MIT 协议开源，构建脚本会把所有下载的依赖收在工作区内，安装包由 GitHub Actions 在三个平台上分别产出。

05 — 问答

常见问题

怎么升级到新版本？

不用重新下载安装包。Windows 版启动时会静默检查并在后台下载新版本，设置 → 更新里点「立即重启安装」即可；也可以在那里手动检查、查看进度。升级会先卸载旧版本，书架与阅读进度默认保留。macOS 与 Linux 会引导到 Releases 下载对应的 dmg / deb / AppImage。

阅笺是免费的吗？

是。阅笺以 MIT 协议完全开源，桌面端全部功能免费，没有会员、订阅或内购。

我的文档会被上传到服务器吗？

不会。阅笺没有账号体系、没有云同步、没有遥测。文档与阅读记录始终留在本机，断网也能读完；唯一会主动联网的是可选的开源字体下载与更新检查，两者都不携带文档内容。

支持哪些文档格式？

PDF、电子书（EPUB / FB2 / FB2.ZIP / MOBI / AZW3 / CBZ）、Markdown（.md / .markdown）以及纯文本（txt / log / csv 与三十余种代码、配置扩展名）。电子书支持单页 / 双页、分页与连续滚动、书签、全书搜索、朗读、自动滚动与划线笔记；Markdown 按 GitHub 风格渲染；纯文本自动识别编码，超过 8 MB 的日志按行索引窗口加载。

支持 Windows、macOS 和 Linux 吗？

三端都有安装包。Windows 提供 NSIS 安装程序，macOS 提供 Intel 与 Apple Silicon 通用的 dmg，Linux 提供 deb 与 AppImage。系统要求：Windows 10 1803+、macOS 10.15+、带 WebKitGTK 4.1 的现代发行版。

macOS 提示"无法验证开发者"怎么办？

安装包尚未做 Apple 公证。在访达中右键点击应用并选择「打开」，或执行 xattr -dr com.apple.quarantine "/Applications/YueJian Reader.app" 后再启动。

配置和阅读进度保存在哪里？

保存在程序安装目录下的 data/ 文件夹：state.json（书架、设置、进度、划线与笔记）、search/（跨书检索索引）与 fonts/（按需下载的字体），另有 WebView 缓存。不写入系统其他位置，复制整个程序目录即可迁移全部阅读记录。

第一次使用需要联网吗？

不需要。打开、阅读、搜索、划线、笔记与导出全部离线完成。只有两个可选动作会联网：从官方源下载开源字体（每款下过一次即离线可用），以及 Windows 版启动时检查更新；两者都可以完全不用。

可以参与开发吗？

可以。源码、构建脚本与设计文档都在 GitHub 仓库，欢迎提交 Issue 与 Pull Request。
