# 文本格式支持 · 功能规划

> 依据：`docs/text-formats-research.md`。视觉与交互沿用 `docs/design-contract.md` 与现有阅读器骨架，
> 不新增颜色 / 圆角 / 字体。

## 1. 范围

**做**

| 类 | 扩展名 | 呈现 |
| --- | --- | --- |
| 纯文本 | `txt` `text` `log` `nfo` `readme` | 正文排版，可切等宽 |
| 表格 | `csv` `tsv` | 表格视图（粘性表头） |
| 代码 / 配置 | `json` `yml` `yaml` `toml` `ini` `conf` `env` `py` `js` `ts` `tsx` `jsx` `rs` `go` `java` `c` `h` `cpp` `cs` `php` `rb` `sh` `bash` `ps1` `sql` `css` `scss` `less` `html` `xml` `vue` `lua` `gitignore` `dockerfile` | 等宽 + 行号 + 语法高亮 |

**不做（写入文档，避免反复）**：`docx` `rtf` `epub` `odt` `xls*` `pdf` 之外的二进制/容器格式、Office 文档。

## 2. 分期

| 期 | 内容 | 交付判定 | 状态 |
| --- | --- | --- | --- |
| **P1 纯文本打通** | 扩展名表、编码探测（BOM → chardetng → encoding_rs）、`kind: "text"`、书架/筛选/图标适配、正文与等宽双视图、行号与软换行、信息面板 | 能打开 UTF-8 / GBK / UTF-16 的 `.txt` 与 `.log`，编码不乱；侧栏「信息」可核对判定结果 | **已完成（v0.1.26）** |
| **P2 代码高亮** | 语言识别表接 hljs、Tab 宽度、`lang` 字段实际生效、200KB 阈值 + 异步补色 | `.rs` `.json` `.yml` 打开即高亮，行号不错位 | **已完成（v0.1.28）** |
| **P3 表格** | CSV/TSV 解析、粘性表头、列宽、行号 | 带引号与逗号的 CSV 正确分列 | 待开始 |
| **P4 大文件** | 采样行索引、窗口读取 IPC、虚拟滚动、大文件关高亮、搜索下沉 | 100MB 日志可打开、可拖动到底部、内存平稳 | 待开始 |
| **P5 收口** | i18n、docs、smoke 断言、编码手动切换菜单 | `npm run check` + `smoke` 全绿 | 待开始 |

每期独立可发布，P1 就能解决「打不开 txt」这个最刺眼的问题。

### P1 实际交付与计划的差异

1. **行号栏提前到 P1**：计划把它放在 P2，但等宽视图没有行号时分不清「这一行很长」还是「折行了」，验收时会误判，所以和等宽视图一起做。软换行与行号互斥（折行后行号无法与行首对齐），开启软换行自动关行号。
2. **书架角标改为显示扩展名**（TXT / LOG / CSV / RS），而不是统一的「文本」。日志和散文都标「文本」在书架上一模一样，看不出是哪一份。
3. **「信息」面板提前到 P1**：编码判错的唯一线索就是判定结果本身，把它放进 P1 才能让用户在真机上确认 P1 是否真的解决了乱码问题。
4. **大文件走保守截断**而非虚拟滚动：`MAX_VIEW_BYTES = 8MB`，全文读一次、在完整行处截断并显式提示。虚拟滚动留在 P4，是为了避免 P1 同时改编码链又改渲染模型，出问题时无法二分定位。

## 3. 交互规格

### 3.1 打开与书架

- 导入对话框过滤器改为：`文档 (pdf md markdown mdown txt log csv tsv json yml …)` + 「所有文件」。
  选到不支持的扩展名时，提示「不支持的文本格式」，不再静默忽略。
- 书架筛选 chip：`全部 / PDF / MARKDOWN / 文本 / 收藏`（新增「文本」，合并纯文本+代码+CSV）。
- 类型角标：`TXT` / `LOG` / `CSV` / `CODE` 四选一（按扩展名派生，不新增 kind）。
  实现上 `kind: "text"`，角标文案由扩展名决定，避免 kind 爆炸。

### 3.2 阅读工具栏（文本类）

左侧是「视图模式」三态胶囊，替代 PDF 的页码组：

```
[ 正文 | 等宽 | 表格 ]     行号 ☐   换行 ☑   1–200 / 12 480 行
```

- **正文**：宋体、限宽 `--measure`、可选行号（默认关）、软换行（默认开）。
- **等宽**：mono、无限制宽度、行号（默认开）、软换行（默认关，长行横向滚动）。
- **表格**：仅 CSV/TSV 出现，其它类型隐藏。
- 默认模式按扩展名自动选：`.log` / 代码 → 等宽；`.csv` / `.tsv` → 表格；其余 → 正文。
  用户手动切过之后，**本次会话内记住**，不写入设置（避免下次打开别的 txt 被上一次的选择带偏）。

### 3.3 右侧面板

- **信息**（新增 tab，文本类默认选中）：编码（可点开切换）、行数、字符数、文件体积、修改时间、换行符（LF/CRLF）。
- **大纲**：仅 Markdown 有；文本类隐藏该 tab。
- **搜索**：沿用现有面板；大文件时提示「正在已加载区域内搜索」。

### 3.4 空/异常状态

| 情况 | 呈现 |
| --- | --- |
| 二进制伪装成 .txt | 「这看起来不是文本文件（检测到 NUL 字节）」，给「用系统程序打开」按钮 |
| 编码探测置信度低 | 正常显示，信息面板里编码旁加「可能不准？换一个」 |
| 超过 32MB | 正常打开但顶部一条细提示：「大文件模式：语法高亮已关闭，换行已关闭」 |
| 空文件 | 「这是一份空文件」 |

## 4. 排版细节（决定「像不像阅读器」）

- 正文：`font-read`、`font-size: var(--read-size)`、`line-height: var(--read-lh)`、`max-width: var(--measure)`、段间距 `1.1em`。
- 纯文本按空行分段：连续两个及以上 `\n` 视为段落分隔；单换行在正文模式下视为软换行（不额外加段距）。
- 等宽：`font-mono`、`font-size: 12.5px`、`line-height: 1.6`、`tab-size: 4`。
- 行号栏：右对齐、`--ink-3`、`user-select: none`、宽度按最大行号位数计算，与代码区之间一条 `--line` 竖线。
- 高亮主题：hljs 自带主题与纸感冲突，**只覆盖 6 个色**（关键字/字符串/注释/数字/标题/函数），
  全部从 `--accent` / `--cat-*` 派生，三个主题各一套（夜读下自动提亮）。

## 5. 数据结构变更

- `Book.kind` 新增 `"text"`；`Book.progress.pages` 对文本类恒为 0，只用 `ratio`。
- `OpenDoc` 新增变体：

```rust
Text {
    path: String,
    size: u64,
    encoding: String,   // "UTF-8" / "GB18030" / "UTF-16LE" …
    lines: u32,
    chars: u32,
    eol: String,        // "LF" / "CRLF" / "CR"
    mode: String,       // "plain" / "code" / "table" / "window"
    lang: String,       // hljs 语言别名，空串表示不高亮
    html: Option<String>,   // 仅 ≤2MB 时下发整篇
}
```

- `settings.json` 不动；视图模式属于会话态。

## 6. 验收标准（可机械验证）

1. `npm run check` 0 问题；`npm run smoke` 全绿，新增断言：
   - 打开 UTF-8 `.txt`：标题取首行、信息面板编码显示 `UTF-8`；
   - 打开 GBK `.txt`：不报错、中文可读、编码显示 `GB18030`；
   - 打开 `.rs`：行号栏存在、`pre code` 上有 hljs class；
   - 打开带引号逗号的 `.csv`：列数正确、表头 sticky；
   - 打开 40MB `.log`：能渲染、内存不随滚动增长、大文件提示出现。
2. 视图模式三态可切，切到「表格」仅在 csv/tsv 出现。
3. 三个主题下正文、行号、高亮的对比度都 ≥ 4.5:1（主正文）。
4. 打开 100MB 日志到可交互 < 800ms，滚动帧率 ≥ 50fps（开发机）。

## 7. 与既有功能的冲突检查

| 既有功能 | 影响 | 处理 |
| --- | --- | --- |
| 双栏联动 | 文本类 ratio 语义一致，可联动 | 保持 |
| 阅读进度 | ratio 复用 | 无需迁移 |
| 搜索 | DOM 遍历在虚拟滚动下失效 | P4 下沉 Rust，P1–P3 先用 DOM |
| 演示模式（present） | 文本类不适用 | 工具栏隐藏该按钮 |
| 导出/打印 | 未实现 | 不涉及 |
