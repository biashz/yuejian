# 界面设计 — 电子书阅读体验（双模式 · 动效 · 朗读 · 自动 · 选区 · 刻度）

> 状态：设计定稿（阶段三）· 依赖 `docs/design-contract.md`（视觉 token 唯一来源）
> 交互依据：`docs/feature-ebook-reading.md`；可运行原型：`prototype/ebook-reading/index.html`（42/42 断言通过）

## 1. 设计目标

六个能力共用一条原则：**阅读区一寸不让，控件全部「贴边生长」**。

- **底部工具带（「书口」）**是电子书独有的容器：通栏停靠在阅读区底边，不浮、不圆角、不压正文。左端常驻当前章节（书眉），中间一条通栏进度轨道，右端成组摆放**模式 / 朗读 / 自动 / 双页 / 书签**。它每栏各有一条，只有活动栏那条渲染；书高 46、按钮 26×26 radius 4——比 PDF / 文本的浮动胶囊小一号、方一点，因为它是版面的一部分。运行态用既有 `.is-on` 语言（`--accent-weak` 底 + 朱砂图标）。
- **阅读区是「桌面 + 书页」**：阅读区底色收深一档当桌面，正文页是 inset 14 / 16 的独立书页（`--surface` 底、1px 发丝边、radius 4、`--shadow-md`），底边与书口带相接。PDF 仍是「整幅画布上的纸」，两边的空间语言就此分开。
- **辅助条**（朗读态 / 自动态共用一个容器）仍是浮层：底部居中、`--surface` 底、顶边 2px 朱砂（契约弹层语言）、`--shadow-md`。它只在运行时出现，浮在书口带与预览气泡上方（bottom 48）。
- **选区条**不重画：第一行五色笔点逐字不变，第二行「复制 / 笔记 / 删除」用 11px 文字按钮 + 发丝线分隔，与现有 `.hl-del` 同一字号族。笔记 popover 是弹层语言的直系后代（顶边朱砂 2px）。
- **进度刻度**是轨道上的 2px 竖线（`--line-strong`），预览气泡是墨底胶囊（与 toast 同族但更小：11px、radius 8）。两者都只在「拖」的时候说话。
- **朗读句高亮**用 `--accent-weak` 底 + 同色 2px 外扩——比划线五色更淡一档，因为它是「正在读」的 transient 状态，不是用户留下的痕迹。

不新增任何色相：全部组件只引用契约既有 token；划线五色沿用 `highlight.js` 的字面量笔色（iframe 内 SVG 读不到主文档变量，契约 §2.1 已登记）。

## 3. 状态与反馈

| 状态 | 视觉 |
| --- | --- |
| 模式运行态 | 按钮 `.is-on` + 标签换字；滚动模式双页按钮 `hidden`（不是禁用——单栏是滚动的定义） |
| 固定版面 | 模式按钮 disabled + title「固定版面保持翻页」；朗读按钮 hidden；自动按钮保留 |
| 朗读运行 / 暂停 | 主按钮 ❚❚ / ▶ 互换；暂停时句高亮保留（读到哪里停在哪里）；字幕保留 |
| 朗读无本地嗓音 | 条仍开：主按钮 disabled + `.assist-note`「系统没有可用的本地嗓音」；语速/嗓音 select 禁用 |
| 自动运行 / 暂停 | 主按钮文字「暂停 / 继续」；用户 wheel / pointerdown 即暂停（条不消失，等「继续」） |
| 互斥 | 开朗读停自动、开自动停朗读：被停的一方条退场、按钮 `.is-on` 摘掉，无 toast（视觉已说明） |
| 书末 / 章末 | 朗读书末：stop + toast「朗读完毕」；自动书末：stop + toast「已到书末」（既有 edge toast 同族） |
| 选区无 CFI（固定版面） | 不弹条（既有规则不变） |
| 笔记超长 | 计数变朱砂 + 保存禁用；不弹错误 toast |
| 复制成功 / 失败 | toast「已复制」/ 既有错误 toast；选区条即关 |
| 拖拽进度 | 气泡出现（opacity 180ms）+ 轨道填充跟随手指；松手气泡退场、才跳转 |
| 字体未下载 | 行右侧写「下载」；点了转百分比，整组压暗并锁点；成功即选中、状态改「使用中」并 toast 字体名 |
| 字体下载失败 | 状态字改「重试」（朱砂），toast「字体下载失败：原因」；再点即重试，不弹模态 |
| 字体已下载 | 状态字「✓」，样例字格直接用该字体渲染（一张活字样表）；移除需行 hover 才出现的删除键 |
| 移除正在用的字体 | 文件删除、设置退回系统宋体、正文立即重排；toast「已移除字体」 |
| reduce-motion | 翻页三档表现均 none；气泡/条退场改为即时；自动滚动保留 |

## 4. 动效

| 动作 | 规格 |
| --- | --- |
| 翻页 slide | 引擎 `animated`：300ms easeOutQuad（vendored paginator 自带，不重写） |
| 翻页 fade | 宿主 opacity 0→1、260ms `--ease`；只动画 opacity，不位移 |
| 辅助条入场 | translateY(8px)→0 + opacity、260ms `--ease`；退场反向 180ms |
| 选区条 / 笔记 popover | 既有 hl-menu 入场不变（opacity + scale .96→1、180ms） |
| 句高亮切换 | 无过渡（瞬移）——朗读节奏 1–2s/句，过渡会拖尾 |
| 气泡 | opacity 180ms；位置即时跟随 |
| 模式切换 | 无跨模式过渡（重排是瞬间事实，假过渡会骗眼睛）；位置由 CFI 保住 |

## 5. 降级与边界

- 窄窗（<1024px）：版式面板走既有抽屉；辅助条 `max-width:92%` 保证不溢出；字幕省略优先于 select（select 先缩到 90px）；书口带固定高 46，轨道自动收窄，章节名先省略。
- 双栏：每栏各有一条书口带，只有活动栏那条渲染（进度滑杆 id 因此不会重复）；辅助条只挂活动栏；切活动栏即停辅助（方向盘归属变化）。
- 键盘焦点在 textarea / select / input 时全部阅读快捷键让路（既有 keys.js 规则）。
- Esc 链插入位置：hl-menu → **辅助条（停朗读/自动）** → note popover → 既有链。先停辅助是因为它持续占用 Space 与方向盘。
- 导出 Markdown：笔记行 `**笔记：** …` 与颜色行并列；无笔记的旧划线输出逐字不变。
