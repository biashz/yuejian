# 阅笺 · YueJian Reader — 产品功能规划

> 一款面向长文阅读的本地桌面阅读器，统一承载 PDF 与 Markdown 两种文档。
> 技术底座：Rust + Tauri 2 + Web 前端（PDF 渲染采用 pdf.js）。

## 1. 产品定位

| 项目 | 说明 |
| --- | --- |
| 一句话定位 | 把 PDF 论文与 Markdown 笔记放进同一个安静的阅读空间 |
| 目标用户 | 研究者、工程师、写作者、需要长时间阅读与摘录的人 |
| 核心价值 | 一个窗口、一套排版语言、一条连续的阅读动线，不做云、不做社交 |
| 设计基调 | 编辑设计（Editorial）取向：纸感、留白、衬线字体、克制的朱砂色点缀 |
| 差异化 | PDF 的“纸面感”与 Markdown 的“活排版”共享同一套主题、进度、目录与阅读设置 |

### 非目标（明确不做）

- 不做 PDF 编辑、批注云同步、协作、账号体系。
- 不做在线书城与内容分发。
- 首版不引入数据库服务，全部数据落地为本地 JSON。

## 2. 用户场景

1. **论文精读**：打开一份 PDF，左侧目录跳章节，双击选中文字复制，阅读进度自动记住，下次打开回到原页。
2. **笔记回看**：打开一个 Markdown 文件，按标题层级生成目录，代码块高亮，可调整字号与行宽。
3. **长期书架**：把常用文档加入书架，按最近阅读排序，一眼看到每本书的阅读进度。
4. **随手看一眼**：刚从别处拿到一个 `.txt` / `.log` / `.csv`，不想为了看几行去开编辑器；直接拖进窗口，中文不会乱码，长行可以选折行或横向滚动。
4. **夜间阅读**：一键切换夜读主题，纸张底色、文字对比度、代码配色同步变化。

## 4. 功能详述

### 4.1 书架 Library

- **导入**：`打开文件`按钮调用系统文件对话框（`.pdf` / `.md` / `.markdown` 与常见文本、代码、配置扩展名）；也支持把文件拖入窗口，不支持的类型跳过并计数提示。
- **条目信息**：标题（优先文档元数据，其次文件名）、类型徽标、页数/字数、最近阅读时间、进度百分比。
- **排序**：按最近打开时间倒序。收藏既是筛选条件也是封面标记，不改变排序。
- **持久化**：写入 `state.json` 的 `books` 数组，记录路径、标题、类型、进度、收藏与最后打开时间。
- **空状态**：插画式排版 + 导入引导，不做无意义的灰色方块。

### 4.2 分类 Categories

- **模型**：一份文档只属于一个分类（单一分类，不做多标签）；不属于任何分类的文档归入「未分类」，它是一个真实可寻址的状态而不是「缺少数据」。
- **分类区**：书架面板内、类型筛选之下的独立区块，列出「全部分类 / 各分类 / 未分类」及各自数量；点击即筛选，再点同一项取消；可折叠，列表最高 168px 后内部滚动。
- **筛选语义**：分类轴与上方的类型轴（全部 / PDF / MARKDOWN / 文本 / 收藏）以及搜索关键词是**正交叠加**关系，三者同时生效；区块标题会显示当前组合（如「论文 · PDF」），并提供「清除筛选」一键复位。「继续阅读」与顶部统计保持全局口径，不随筛选跳动。
- **归类入口**：① 把文档拖到分类行；② `Ctrl/Cmd + 点击` 多选后，在批量条里选目标分类；③ 拖到「未分类」或批量选「未分类」即移出分类。拖回原分类不写盘、不提示。
- **分类管理**：`＋` 新建；分类行悬停出现 `⋯`，打开编辑弹层可改名、改配色、删除。删除含文档的分类需二次确认，并明确说明文档会转为未分类、不会被移除；删除空分类直接执行。
- **校验**：名称去空格后 1–20 字，不可与其它分类重名（忽略大小写）；分类数量上限 40。校验在 Rust 侧统一执行，前端仅提前禁用按钮。
- **配色**：每个分类从 6 色固定色板取一色，新建时自动选中第一个未被占用的颜色；配色只用于色点，不改变文档封面颜色。

### 4.3 PDF 阅读

- 使用 pdf.js 渲染到 canvas，叠加透明文本层以支持选择与复制。
- 连续滚动，滚动时按可视区域懒加载页面，避免一次渲染全部页面。
- 工具栏：上一页 / 页码输入 / 总页数 / 下一页 / 缩小 / 缩放比例菜单（常用比例 + 适合宽度 / 适合页面）/ 放大 / 放映 / 侧栏开关 / 分栏。
- 侧栏三个标签页：目录（outline）、缩略图、搜索（`findController` 全文档匹配 + 高亮）。
- 进度记录：当前页 + 缩放比例 + 滚动偏移。

### 4.4 Markdown 阅读

- **解析在 Rust**：`comrak`（GitHub 风格，启用表格、任务列表、脚注、删除线、自动链接），输出安全 HTML。
- **目录在 Rust 生成**：扫描 h1–h3，返回 `{ level, id, text }` 列表。
- **代码高亮在前端**：`highlight.js` 本地打包，避免 Rust 侧引入重型依赖。
- **图片**：相对路径经 `asset` 协议转换为可访问 URL。
- **排版**：正文最大宽度可调，标题使用楷体、正文使用宋体，行高 1.9，支持首段下沉。

### 4.5 文本阅读

覆盖纯文本、日志、CSV 与三十余种代码 / 配置扩展名。设计取舍是「先保证不丢内容、不出乱码」，语法高亮放在后续阶段。

- **编码三段式**：BOM 作为硬证据优先；无 BOM 时用 `chardetng`（Firefox 同源检测器）读前 8KB 判定；再由 `encoding_rs` 解码，无法映射的字节替换而非整篇失败。中文 Windows 记事本存的 GBK `.txt` 因此能正常打开。
- **双视图**：`正文`（宋体、限宽、空行分段）与 `等宽`（逐行对齐、可开行号）。默认视图按扩展名判定；用户选择只在会话内保留。
- **软换行与行号互斥**：一旦折行，行号无法与行首对齐，因此打开软换行会自动关闭行号，并在按钮可用性上体现。
- **恒定节点渲染**：整篇只用两个 `<pre>`（行号 + 正文），节点数与行数无关；按行建节点会让 5MB 日志产生十几万节点。
- **大文件**：超过 8MB 只读前 8MB，在完整行处截断并显式提示，「信息」面板同步标注。软换行与高亮在超限时明确关闭而不是静默出错。
- **类型判定单一来源**：支持哪些扩展名由 Rust 侧 `text::is_text` 一处判定，前端不维护第二份白名单；导入时跳过的不支持文件按数量提示。

### 4.6 阅读体验

| 设置项 | 取值 |
| --- | --- |
| 主题 | 纸白 `paper` / 夜读 `night` / 护眼 `sepia` |
| 正文字号 | 15 / 17 / 19 / 21 px（工具栏 A− / A+ 按档步进） |
| 行高 | 1.7 / 1.9 / 2.1 |
| 版心宽度 | 620 / 720 / 820 px |
| 缩放 | 默认「适合宽度」，25%–400% 分档步进，另有「适合页面」 |
| 专注模式 | 隐藏图标栏、书架面板与状态栏 |

### 4.7 命令面板

`Ctrl/Cmd + K` 唤起，支持：搜索书籍、导入文件、切换主题、切换专注模式、分屏 / 合并双栏、进入演示、打开设置、返回书架。键盘 ↑↓ 选择，Enter 执行。

### 4.8 双栏对照

- **分屏**：工具栏的分栏按钮或 `Ctrl/Cmd + \` 拆分 / 合并。拆分时右栏默认载入当前文档，两栏各自独立翻页、缩放、搜索。
- **活动栏**：指针按下或滚轮进入某栏即成为活动栏，工具栏、目录面板、状态栏都以活动栏为准；两栏各有栏头显示书名与页码。
- **联动**：仅当两栏打开同一份文档时出现联动按钮，开关状态随设置持久化。联动时按「页码 + 页内相对比例」对齐，而不是只同步页码——两栏可视高度不同也能对齐同一段文字。
- **合并**：合并时保留活动栏的文档；若左栏为空而右栏有文档，文档会接回左栏，不会出现「合并后什么都没有」。
- **会话性**：分栏是临时操作，启动时一律单栏，不写入设置。

### 4.9 演示模式

- **入口**：PDF 工具栏的放映按钮、`F5`，或命令面板「进入演示」。
- **放映**：进入系统全屏，单页居中显示，四周留 12px 边。左侧半屏 / 上一页键后退，右侧半屏 / 下一页键前进，滚轮同样可翻页（触控板小增量先累积，避免一次滑动连翻多页）。
- **首帧**：进入时复用阅读器已渲染的页面做快照，全屏过渡结束再补一次高清渲染，切换过程中不出现黑底或闪烁。
- **退出**：`Esc` / `F5` / 系统退出全屏都可结束放映，并回到放映时停留的那一页。
- **限制**：仅 PDF 可放映；Markdown 触发时给出提示。

### 4.10 更新

- **自动检查**：启动约 3 秒后静默请求 GitHub Releases 的最新发布；不弹窗，只有发现新版本时给一条提示。
- **后台下载**：Windows 发现新版本后直接后台下载安装包，进度显示在设置 → 更新；macOS / Linux 不自动下载，引导前往发布页。
- **安装**：下载完成后「立即重启安装」，应用退出、安装器接管；安装器先卸载旧版本，`data/` 默认保留。
- **手动检查**：设置 → 更新可随时检查版本、查看进度、打开 Release 页；「启动时自动检查更新」可关闭。
- **失败处理**：网络异常时静默检查不打扰用户，手动检查则显示错误原因并提供重试。

### 4.11 界面语言

- 中文 / English 可即时切换，入口在标题栏的语言按钮与设置面板，无需重启。
- 切换时重填静态文案并重绘所有动态区域（书架、工具栏、目录、状态栏、设置、更新卡片），只影响界面，不改动文档内容与阅读进度。
- 选择写入 `settings.language`，下次启动沿用；安装向导同样提供语言选择。

## 5. 非功能需求

- **启动**：冷启动 ≤ 2 s（不含首次打开大 PDF）。
- **内存**：100 页 PDF 连续滚动渲染的可视页不超过 5 页。
- **安全**：Tauri 白名单最小化，仅开放 `dialog`、`fs`（只读指定文件）、`asset` 协议；Markdown 输出经净化，不执行脚本。
- **可访问性**：所有可交互元素有 `:focus-visible` 焦点环；对比度 ≥ 4.5:1。
- **跨平台**：Windows 优先，macOS / Linux 保留构建能力。

## 6. 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 应用框架 | Tauri 2 | Rust 后端 + 系统 WebView，包体小，权限模型清晰 |
| 前端 | 原生 HTML / CSS / JS（ES Module） | 无打包步骤，启动快，便于与原型 1:1 还原 |
| PDF 渲染 | pdf.js (Mozilla) | 成熟、支持文本层与搜索、可离线分发 |
| Markdown | comrak | Rust 生态中最完整的 GFM 实现 |
| 文本编码 | encoding_rs + chardetng | Firefox 同源实现，GBK / GB18030 / UTF-8 全覆盖，纯 Rust 无需外部库 |
| 代码高亮 | highlight.js | 前端轻量，按语言按需注册 |
| 持久化 | serde_json + 应用数据目录 | 首版无需数据库，便于用户查看与备份 |
| 图标 | Lucide（内联 SVG） | 线性图标风格统一，零外部依赖 |

## 7. 数据模型

单一 `state.json`，位于运行时数据目录（安装后为可执行文件同级的 `data/`）。写入走「临时文件 + 重命名」，中断不会损坏书架。

```jsonc
{
  "version": 1,
  "books": [
    {
      "id": "3f9a1c",              // 文件路径哈希，重复导入不产生副本
      "path": "D:\\docs\\paper.pdf",
      "title": "纸页上的呼吸",
      "author": "",
      "kind": "pdf",               // pdf | markdown | text
      "size": 2483102,
      "pages": 48,
      "words": 0,
      "addedAt": 1762300000000,    // 毫秒时间戳
      "lastOpenedAt": 1762390000000,
      "favorite": false,
      "categoryId": "c1a3f2",      // 所属分类 id；空串表示「未分类」
      "progress": { "ratio": 0.36, "page": 12, "zoom": 1.0 }
    }
  ],
  "categories": [
    {
      "id": "c1a3f2",
      "name": "论文",
      "color": "clay",             // clay | indigo | olive | amber | plum | slate
      "createdAt": 1762290000000
    }
  ],
  "settings": {
    "theme": "paper",              // paper | night | sepia
    "fontSize": 17,                // 15 | 17 | 19 | 21
    "lineHeight": 1.9,             // 1.7 | 1.9 | 2.1
    "measure": 720,                // 620 | 720 | 820
    "showCtx": true,
    "zen": false,
    "split": false,                // 预留位：分栏为会话级操作，启动时一律单栏
    "linkSync": true,              // 双栏同文档时是否联动
    "language": "zh",              // zh | en
    "autoCheckUpdate": true
  }
}
```

- 时间戳为毫秒（`u64`），前端 `formatRelative` 直接与 `Date.now()` 相减。
- `settings` 使用容器级 `serde(default)`：升级后旧文件缺少新增字段时按默认值补齐，不会读取失败。
- `split` 目前是预留字段：分栏是会话级临时状态，启动时一律单栏，当前版本既不读也不写。
- `categories` 与 `Book.categoryId` 是 0.2.0 追加的字段，靠字段级 `serde(default)` 兼容旧数据：
  旧文件读入后 `categories` 为空数组、所有文档 `categoryId` 为空串，语义上就等于「全部未分类」，因此不需要任何迁移代码。
- 分类型不设 `order` 字段：按 `createdAt` 升序展示。等真的支持拖拽排序时再加字段与迁移，避免出现「声明了却从不写入」的字段。
