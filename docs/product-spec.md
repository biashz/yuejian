# 阅笺 · YueJian Reader — 产品功能规划

> 一款面向长文阅读的本地桌面阅读器，统一承载 PDF 与 Markdown 两种文档。
> 技术底座：Rust + Tauri 2 + Web 前端（PDF 渲染采用 pdf.js）。

## 1. 产品定位

| 项目 | 说明 |
| --- | --- |
| 一句话定位 | 把 PDF 论文与 Markdown 笔记放进同一个安静的阅读空间 |
| 目标用户 | 研究者、工程师、写作者、需要长时间阅读与摘录的人 |
| 核心价值 | 一个窗口、一套排版语言、一条连续的阅读动线，不做云、不做社交 |
| 设计基调 | 编辑设计（Editorial）取向：纸感、留白、衬线字体、克制的朱砂色点缀 |
| 差异化 | PDF 的“纸面感”与 Markdown 的“活排版”共享同一套主题、进度、目录与阅读设置 |

### 非目标（明确不做）

- 不做 PDF 编辑、批注云同步、协作、账号体系。
- 不做在线书城与内容分发。
- 首版不引入数据库服务，全部数据落地为本地 JSON。

## 2. 用户场景

1. **论文精读**：打开一份 PDF，左侧目录跳章节，双击选中文字复制，阅读进度自动记住，下次打开回到原页。
2. **笔记回看**：打开一个 Markdown 文件，按标题层级生成目录，代码块高亮，可调整字号与行宽。
3. **长期书架**：把常用文档加入书架，按最近阅读排序，一眼看到每本书的阅读进度。
4. **夜间阅读**：一键切换夜读主题，纸张底色、文字对比度、代码配色同步变化。

## 4. 功能详述

### 4.1 书架 Library

- **导入**：`打开文件`按钮调用系统文件对话框（`.pdf / .md / .markdown`）；也支持把文件拖入窗口。
- **条目信息**：标题（优先文档元数据，其次文件名）、类型徽标、页数/字数、最近阅读时间、进度百分比。
- **排序**：最近阅读优先；收藏条目置顶。
- **持久化**：`library.json`（应用数据目录），记录路径、标题、类型、进度、收藏、最后打开时间。
- **空状态**：插画式排版 + 导入引导，不做无意义的灰色方块。

### 4.2 PDF 阅读

- 使用 pdf.js 渲染到 canvas，叠加透明文本层以支持选择与复制。
- 连续滚动，滚动时按可视区域懒加载页面，避免一次渲染全部页面。
- 工具栏：上一页 / 下一页 / 页码输入 / 缩小 / 百分比 / 放大 / 适合宽度 / 适合页面 / 侧栏开关。
- 侧栏三个标签页：目录（outline）、缩略图、搜索（`findController` 全文档匹配 + 高亮）。
- 进度记录：当前页 + 缩放比例 + 滚动偏移。

### 4.3 Markdown 阅读

- **解析在 Rust**：`comrak`（GitHub 风格，启用表格、任务列表、脚注、删除线、自动链接），输出安全 HTML。
- **目录在 Rust 生成**：扫描 h1–h3，返回 `{ level, id, text }` 列表。
- **代码高亮在前端**：`highlight.js` 本地打包，避免 Rust 侧引入重型依赖。
- **图片**：相对路径经 `asset` 协议转换为可访问 URL。
- **排版**：正文最大宽度可调，标题使用楷体、正文使用宋体，行高 1.9，支持首段下沉。

### 4.4 阅读体验

| 设置项 | 取值 |
| --- | --- |
| 主题 | 纸白 `paper` / 夜读 `night` / 护眼 `sepia` |
| 正文字号 | 15–24 px |
| 行高 | 1.6 / 1.8 / 2.0 |
| 版心宽度 | 620 / 720 / 820 px |
| 专注模式 | 隐藏书架侧栏与状态栏 |

### 4.5 命令面板

`Ctrl/Cmd + K` 唤起，支持：搜索书籍、跳转章节、切换主题、打开设置、导入文件。键盘 ↑↓ 选择，Enter 执行。

## 5. 非功能需求

- **启动**：冷启动 ≤ 2 s（不含首次打开大 PDF）。
- **内存**：100 页 PDF 连续滚动渲染的可视页不超过 5 页。
- **安全**：Tauri 白名单最小化，仅开放 `dialog`、`fs`（只读指定文件）、`asset` 协议；Markdown 输出经净化，不执行脚本。
- **可访问性**：所有可交互元素有 `:focus-visible` 焦点环；对比度 ≥ 4.5:1。
- **跨平台**：Windows 优先，macOS / Linux 保留构建能力。

## 6. 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 应用框架 | Tauri 2 | Rust 后端 + 系统 WebView，包体小，权限模型清晰 |
| 前端 | 原生 HTML / CSS / JS（ES Module） | 无打包步骤，启动快，便于与原型 1:1 还原 |
| PDF 渲染 | pdf.js (Mozilla) | 成熟、支持文本层与搜索、可离线分发 |
| Markdown | comrak | Rust 生态中最完整的 GFM 实现 |
| 代码高亮 | highlight.js | 前端轻量，按语言按需注册 |
| 持久化 | serde_json + 应用数据目录 | 首版无需数据库，便于用户查看与备份 |
| 图标 | Lucide（内联 SVG） | 线性图标风格统一，零外部依赖 |

```jsonc
  "version": 1,
  "books": [

      "title": "纸页上的呼吸",
      "kind": "pdf",              // pdf | markdown
      "size": 2483102,
      "added_at": 1762300000,
      "last_opened_at": 1762390000,
      "favorite": false,
      "progress": { "page": 12, "total": 48, "scroll": 0.36, "zoom": 1.0 }
    }
  ]
}

{
  "theme": "paper",
  "fontSize": 18,
  "lineHeight": 1.9,
  "measure": 720,
  "sidebarVisible": true,
  "zenMode": false
}
```
