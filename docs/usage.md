# 阅笺用户手册

面向使用者的操作说明。开发与构建相关内容见 [README](../README.md)，产品与设计细节见 [产品功能规划](product-spec.md) 与 [设计契约](design-contract.md)。

## 1. 安装

安装包统一发布在 [GitHub Releases](https://github.com/biashz/yuejian/releases)，所有版本由 GitHub Actions 在三端分别构建。

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Windows | `YueJian.Reader_<版本>_x64-setup.exe` | 双击运行，按向导安装到当前用户目录 |
| macOS | `YueJian.Reader_<版本>_universal.dmg` | 打开 dmg，把「阅笺」拖入「应用程序」 |
| Linux | `YueJian.Reader_<版本>_amd64.deb` | `sudo dpkg -i <文件名>.deb` |
| Linux | `YueJian.Reader_<版本>_amd64.AppImage` | `chmod +x <文件名>` 后直接运行 |

首次启动的注意事项：

- **macOS**：安装包未做 Apple 公证，系统可能提示“无法验证开发者”。在访达中右键点击应用选择「打开」，或执行
  `xattr -dr com.apple.quarantine /Applications/阅笺.app` 后再启动。
- **Windows**：依赖系统 WebView2。Windows 11 已内置，Windows 10 若缺失需先安装 Microsoft Edge WebView2 Runtime。
- **Linux**：需要 WebKitGTK 4.1；AppImage 自带其余依赖，但不会解压到系统目录。

## 2. 界面速览

应用窗口分为六个固定区域：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 标题栏 | 顶部 36px | 应用名、当前文档名、主题切换、命令面板 |
| 图标栏 | 左侧 56px | 书架 / 阅读 / 搜索 / 设置，位置与顺序固定 |
| 书架面板 | 左侧 304px | 文档库、搜索框、筛选、导入入口（可折叠） |
| 主舞台 | 中间 | 书架视图或阅读视图 |
| 目录面板 | 右侧 268px | 大纲 / 缩略图 / 搜索，仅阅读时出现 |
| 状态栏 | 底部 26px | 当前文档、主题、页码与快捷键提示 |

## 3. 导入文档

支持两种方式，目标格式为 `.pdf`、`.md`、`.markdown`：

1. 点击书架面板右上角的 `+`，或底部「导入本地文档」按钮；
2. 直接把文件拖入窗口任意位置。

同一路径的文档只会入架一次（书架 id 由路径哈希生成），重复导入不会产生副本。

## 4. 书架

- **搜索**：书架面板顶部输入框按书名与作者过滤；`Ctrl/Cmd + K` 打开的是全局命令面板。
- **筛选**：全部 / PDF / Markdown / 收藏四档。
- **排序**：按最近打开时间倒序，不支持手动排序或收藏置顶。
- **进度**：每个条目下方显示阅读进度条。
- **收藏**：点击「全部文档」封面卡片右上角的星标切换，阅读视图文档栏也有同样的星标按钮。
- **移除**：点击条目右侧的删除按钮，仅从书架移除记录，不会删除磁盘上的原文件。

## 5. 阅读 PDF

打开 PDF 后进入阅读视图，正文为连续滚动的页面，可直接用鼠标选中并复制文字。

阅读视图顶部是文档栏：左侧「书架」按钮返回书架，中间显示标题与元信息，右侧依次为收藏、专注模式、目录面板开关。

PDF 的翻页与缩放工具栏依次为：上一页 / 页码输入框 / 总页数 / 下一页 / 缩小 / 缩放比例（点击恢复 100%）/ 放大 / 适合宽度 / 目录面板开关。

右侧目录面板有三个标签：

| 标签 | 说明 |
| --- | --- |
| 目录 | 读取 PDF 内置大纲，点击跳转章节 |
| 缩略图 | 按页预览，点击定位 |
| 搜索 | 全文关键词匹配，命中处高亮，回车跳转下一处 |

阅读位置（页码、缩放比例与滚动比例）会自动写入 `state.json`，下次打开自动恢复。

## 6. 阅读 Markdown

Markdown 在 Rust 侧渲染为安全 HTML 后再交给前端显示，支持 GitHub 风格语法：

- 工具栏为 `A−` / 当前字号 / `A+` / 行高切换 / 版心切换 / 目录面板开关；
- 表格、任务列表、引用、脚注、删除线、自动链接；
- 一至三级标题自动生成锚点与右侧目录，滚动时目录高亮当前章节；
- 代码块按语言高亮，行内代码使用等宽字体；
- 相对路径图片经 `asset` 协议转换为可访问地址，随文档所在目录解析。

正文使用宋体、标题使用楷体，行高 1.9 起，适合长时间阅读。

## 7. 阅读设置

点击图标栏的「设置」，或在命令面板中搜索「设置」打开设置面板，改动即时生效，无需确认或重启：

| 设置项 | 可选值 |
| --- | --- |
| 主题 | 纸白 / 夜读 / 护眼 |
| 正文字号 | 15 / 17 / 19 / 21 px |
| 行高 | 紧凑 1.7 / 标准 1.9 / 宽松 2.1 |
| 版心宽度 | 窄 620 / 标准 720 / 宽 820 px |
| 打开文档时显示目录 | 开 / 关 |
| 专注模式 | 隐藏图标栏、书架面板与状态栏 |

「恢复默认」把以上设置重置为纸白、17px、1.9 行高、720 版心。

## 8. 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/Cmd + K` | 打开 / 关闭命令面板（搜书、跳章节、切主题、开设置、导入） |
| `Ctrl/Cmd + O` | 导入本地文档 |
| `Ctrl/Cmd + B` | 显示 / 隐藏目录面板（阅读时） |
| `Ctrl/Cmd + D` | 切换专注模式（阅读时） |
| `←` / `→` | PDF 上一页 / 下一页（阅读时） |
| `+` / `-` | PDF 放大 / 缩小（阅读时） |
| `↑` / `↓` | 命令面板中上下选择 |
| `Enter` | 命令面板中执行选中项 |
| `Esc` | 关闭弹层；无弹层时返回书架 |

## 9. 数据位置与迁移

发布版的全部数据位于可执行文件同级的 `data/` 目录：

```
data/
├── state.json      # 书架、阅读进度与设置
└── webview2/       # 系统 WebView 的用户数据目录（Windows 下即 WebView2）
```

- Linux AppImage 的数据写在 `.AppImage` 文件同级目录的 `data/`；
- 调试构建使用项目根目录的 `.data/`；
- 不向 `%APPDATA%`、`~/Library` 或其他系统目录写入任何内容。

**迁移**：关闭应用后复制整个程序目录（或 AppImage 与同级的 `data/`），在新位置启动即可保留书架与进度。**备份**：只需备份 `state.json`。

## 10. 常见问题

**打开文档后书架空白 / 提示找不到文件**
书架只保存文件路径，不复制原文件。原文件被移动、重命名或所在磁盘未挂载时会打不开，重新导入新路径即可。

**阅读进度没有恢复**
进度在滚动与翻页后延迟写入磁盘，若在写入前强制结束进程可能丢失最后一次位置。正常关闭窗口不会丢失。

**PDF 页面空白或显示不全**
先确认文件本身未损坏（可用其他阅读器打开）；加密或仅有扫描图的 PDF 仍可显示图像，但文本层为空，无法选中复制与全文搜索。

**大文件卡顿**
PDF 按可视区域懒加载，但单页含大量高分辨率图像时仍会占用较多内存。可先缩小缩放比例以降低渲染尺寸。

**界面字体与预期不同**
标题使用楷体、正文使用宋体，均取自系统字体。系统缺少对应字体会回退到衬线字体，不影响功能。

**如何卸载**
Windows 在「设置 → 应用」中卸载，macOS 删除应用，Linux 卸载 deb 包。卸载不会自动删除 `data/`，确认不需要阅读记录后可手动删除该目录。
